Software Development · Case Study

PressAV

A 24/7 data-ingestion and broadcast recording microservices platform, co-built from inception for Fosol Software Solutions Inc.

Role
Full-Stack Developer (Contract)
Timeline
June 2024 – Present
Stack
C#, ASP.NET Core, React, TypeScript, Docker, Kafka, WhisperX

Overview

PressAV is a broadcast recording and transcription platform that continuously ingests live channel feeds, schedules recordings, and produces searchable transcripts for newsroom and media clients. I joined at inception and contributed across the full stack — backend services, RESTful APIs, container infrastructure, and the React front end.

Machine Learning Integration

Researched, evaluated, and implemented WhisperX for automated transcription workflows. When requirements shifted toward near-live turnaround, I engineered a custom implementation to meet that performance target without sacrificing transcript accuracy.

Front End

Built responsive interfaces with React.js, Material UI, and headless component solutions — covering live channel guides, recording schedules (single/repeating/perpetual), and a transcript editor with channel tagging and summary generation.

Backend & Infrastructure

Designed backend services and RESTful APIs in C# / ASP.NET Core, containerized with Docker, and used Kafka for event streaming across ingestion services. Infrastructure health and performance (CPU, memory, thread counts, .NET GC/managed memory) is monitored via Grafana dashboards.
